Project: SharePlattr

Stack:
Laravel 12, Inertia.js, React, Vite, Tailwind, MySQL, Docker, Nginx, PHP-FPM.

Important rules:
- Always use Docker commands. Do not assume local PHP, Composer, Node, or MySQL.
- Use docker compose exec app ... or docker compose -f docker-compose.prod.yml ...
- Keep changes minimal and MVP-focused.
- Do not over-engineer with unnecessary services/repositories.
- Prefer simple Laravel controllers, Eloquent, migrations, seeders, and Inertia pages.
- Before changing files, inspect existing routes, controllers, models, migrations, and tests.
- After changes, tell me:
  1. files changed
  2. commands to run
  3. how to test
  4. rollback or common fixes

Current product goal:
Validate the loop: campaign → share → click → conversion → reward → payout request.

Local Docker setup:
- app container runs PHP-FPM, Composer, npm, Artisan, and Vite.
- nginx serves Laravel.
- db is MySQL.
- Use app, nginx, db service names.
- Vite runs on 5173.
- App runs on localhost:8000.

Production:
- DigitalOcean Droplet
- docker-compose.prod.yml
- host Nginx/SSL in front
- app/nginx/db/queue containers
- no public MySQL
- no public Vite
- APP_URL must be https://www.shareplattr.com or https://shareplattr.com
